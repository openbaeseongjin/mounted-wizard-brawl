# 진짜 모델 (v0.5) 출처

게임이 쓰는 파일은 `tools/pack_assets.mjs` 가 원본(`assets/look/`, 저장소에는 안 올린다)에서 안 쓰는 동작·소품을 빼고 meshopt 로 압축해 만든다.
모두 CC0 1.0 이라 표기 의무는 없지만 게임 첫 화면과 itch 페이지에 적는다.

| 게임 파일 | 원본 | 만든 사람 | 라이선스 |

| mage.glb · knight.glb · barbarian.glb · rogue.glb · rogue_hooded.glb | KayKit Character Pack: Adventurers 1.0 · https://github.com/KayKit-Game-Assets/KayKit-Character-Pack-Adventures-1.0 | Kay Lousberg (kaylousberg.com) | CC0 1.0 |
| props.glb: pumpkin | KayKit Halloween Bits 1.0 · pumpkin_orange_jackolantern | Kay Lousberg | CC0 1.0 |
| props.glb: quiver | KayKit Character Pack: Skeletons 1.0 · Skeleton_Quiver | Kay Lousberg | CC0 1.0 |
| props.glb: barrel · keg | KayKit Dungeon Remastered 1.0 · barrel_small, keg | Kay Lousberg | CC0 1.0 |
| map.glb (건물·나무·산·소품 52종) | KayKit Medieval Hexagon Pack 1.0 · https://github.com/KayKit-Game-Assets/KayKit-Medieval-Hexagon-Pack-1.0 (Assets/gltf) | Kay Lousberg | CC0 1.0 |

원본 받기: 위 저장소의 `addons/.../Assets/gltf` 에서 같은 이름의 파일을 `assets/look/`(몸·말), `assets/look/props/`, `assets/look/map/` 에 둔다. 말은 poly.pizza 에서 glb 로.
